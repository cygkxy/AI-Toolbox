# AI 工具箱

自用小工具合集。每个工具独立一个子目录,互不依赖,想用哪个进哪个目录看各自的 README。

## 工具列表

| 工具 | 说明 | 形态 |
|---|---|---|
| [scan-photo-archive](./scan-photo-archive) | 扫码拍照存档:扫设备二维码 → 拍照 → 按设备号自动命名存档 | 纯前端 + Node 静态服务器 |

## 目录约定

```
AI-Toolbox/
└── <工具名>/
    ├── README.md      # 这个工具怎么跑、怎么用
    └── ...            # 工具自己的代码，自包含
```

- 每个工具**自带启动方式和说明**,不假设仓库根目录有什么
- 密钥、证书、构建产物一律不入库(见 `.gitignore`)
- 新增工具:建子目录 + 写 README + 在上面表格里加一行
