一次只扫一个：点「开始扫描」→ 识别成功会自动停下 → 给这台设备拍任意多张 → 再点「扫下一个设备」扫下一个。 想给之前录过的设备补拍，直接点清单里的那一行即可。 「已拍 N 张」是浏览器记的拍摄计数，删掉本地照片不会自动变；手机端点该行的「重置」即可归零。 桌面 Chrome / Edge 点「选择保存文件夹」后会按文件夹里的真实文件重新校准，之后删照片点「按文件夹校准」就同步了。 照片左下角会烧入两行水印：SN：设备号 / 日期：YYYY-MM-DD HH:mm:ss。 页面需运行在 HTTPS 或 localhost 下，否则摄像头会被拒绝。
